# Task 3: journalctl (Linux) / log (macOS)

This was used as log commands for mac 

Here we have few basic command such has it helps us to find the logs happened in kernal level in our computer/system 

## Commands

### log show --last 1h
This command helps us to show logs from past 1hr

### log stream
Helps us to find the live logs in our system 

### log show --predicate 'process == "sudo"'
This filters out the sudo process used
