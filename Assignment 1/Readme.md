## What Each Section Covers

### 1. Docker Images

The multi-stage Docker example builds a Go application and runs it on port 8080. The folder also includes separate Node.js, Python, and Java deployments, along with Dockerfiles and screenshots.

### 2. Docker Fundamentals

This section contains several small Hello World web applications. Each application has its own Dockerfile and README evidence showing how the containers were built and tested.

### 3. Git and GitHub

The Git exercise compares `git commit -m` with `git commit -a -m`, then demonstrates how to cherry-pick one commit from a feature branch onto `main`.

### 4. Shell Scripting

The `system_info.sh` script displays basic system information, accepts a directory name from the user, creates a directory and file, and saves process information using output redirection.

### 5. Docker Networking

This section practises Docker networks, container connectivity, bind mounts, and an overlay network. The README includes the commands and results from the exercises.

### 6. Linux Fundamentals

The Linux work covers links, user management, system logs, and common Linux commands. The folder contains separate task notes for Tasks 2, 3, and 4, together with the related screenshots.

### 7. Networking

The networking section documents commands such as `ip`, `ping`, `traceroute`, `dig`, `nslookup`, `nc`, `netstat`, `whois`, and `tcpdump`. The README includes screenshots and short explanations of the results from my Mac.

## How to Use This Repository

Open the README in any section to see the commands and explanations for that topic. The Docker and shell scripting folders also contain the source files needed to repeat the exercises.

Most examples can be run from a terminal after installing Docker where required. Commands that create containers or networks may need to be cleaned up after testing, so the instructions in each section should be followed in order.
